🚀 How to Run
Browser App No installation required
1
Open the project folder — navigate to Flake Locator Pro/
2
Open index.html in any modern browser — Chrome, Firefox, Safari, or Edge.
Double-click the file, or drag it onto a browser window. No server needed.
3
Load your images — click Load in the Substrate Library and select one or more microscopy image files (JPEG, PNG, TIFF).
4
Calibrate scale — press S, drag across a known scale bar, enter the real-world length in µm, press Set Scale.
5
Detect flakes — press Ctrl D for full auto-detect, or press F to flood-fill individual flakes by clicking.
6
Apply a colormap (optional) — select a colormap from the toolbar dropdown to colour all flake labels by index.
7
Export results — CSV, Excel, high-res JPG, PDF report, or save a full session Backup.
✅ Chrome / Chromium — recommended ✅ Firefox — fully supported ✅ Safari 16+ — supported ✅ Edge — supported ⚠️ IE / old Edge — not supported
⚡ Optional — run via local server (avoids browser file-access restrictions)
# Python 3
cd "Flake Locator Pro"
python -m http.server 8123
# then open → http://localhost:8123
Python CLI Batch processing via terminal
1
Install dependencies
pip install -r requirements.txt
2
Run on a single image
python flake_analyzer.py IMG_0327.jpeg --scale 1.5 --threshold 120
3
Run with GMM background model
python flake_analyzer.py IMG_0327.jpeg --method gmm --scale 1.5
4
Batch process a folder
for f in *.jpeg; do python flake_analyzer.py "$f" --scale 1.5; done
5
Output — a .csv file per image with flake coordinates, dimensions, and contrast values.

Drawing & Annotation Tools
🖐 Pan & Select V
Navigate the canvas. Click a flake to select it and zoom to it; drag to pan. Scroll to zoom. Hold Space + drag to pan from any other tool.
📏 Scale Ruler S
Drag across a known scale bar to calibrate. Enter the real-world length in µm, then press Set. Establishes the px/µm ratio used for all subsequent measurements.
⊕ Set Origin O
Click to place the coordinate origin (0, 0). All flake X/Y positions are reported relative to this point. Origin is shown as a permanent crosshair overlay on the canvas.
▭ Box Annotation B
Click and drag to draw an axis-aligned bounding box over a flake. Reports length, width, area, centroid coordinates, and aspect ratio.
◱ Rotated Box R
3-click rotated rectangle: click p1 → p2 along the long axis edge, then p3 to define the width. Captures orientation angle and oriented bounding-box (OBB) dimensions.
⬡ Polygon P
Click to place vertices around a flake outline; double-click or click near the start node to close. Area computed via shoelace formula, centroid via shape moments, L/W via minimum OBB.
🪣 Flood Fill F
Click a seed pixel inside a flake. Expands to neighbouring pixels within the Tolerance of the seed colour. Traces a Douglas–Peucker boundary polygon; auto-classifies layer thickness via Fresnel optical contrast.
🔍 Auto-Detect Ctrl D
Scans the entire image. Thresholds by grayscale value or colour distance, discards blobs below Min Size, skips the bottom banner and any drawn Ignore Areas, and optionally applies watershed split and morphological cleanup before adding all found flakes.
⬚ Ignore Area
Drag a rectangle to mark a region that should be excluded from auto-detect and flood fill — useful for the scale bar, contamination, or substrate edges. Shown as a red dashed border; can be removed individually.
✂ Snip Crop
Drag to select a rectangular region of the canvas. Exports that region as a cropped JPG, useful for producing publication-ready sub-images of individual flakes of interest.
🗂 Crop Image
Permanently trims the active substrate image to the drawn rectangle. All flake coordinates are automatically adjusted to remain correct relative to the new image bounds.
🔗 Stitch Align
Drag images to position them side-by-side. Auto-Stitch detects Harris corners, matches patch descriptors, and uses RANSAC to compute the 2D alignment offset — works for any overlap direction (horizontal, vertical, diagonal). Falls back to sequential tiling if no overlap is detected.
🎨 Flake Label Colormap
Select a colormap from the Colormap… dropdown in the canvas toolbar to colour all flake annotations by their index across the full colormap range. 39 scientific colormaps are available — perceptually uniform, diverging, sequential, and cyclic. Each flake receives three distinct hues sampled at evenly-spaced offsets within the colormap:
Canvas elementColormap offset
Outline · centroid cross · flake number labelt — base colour for flake i
L × W dimension string (below name)t + 0.33
Length arm line & label · Width arm line & labelt + 0.67
Where t = i / (n − 1), i = zero-based flake index, n = total flakes. Colormaps available: Magma · Inferno · Plasma · Viridis · Turbo · Jet · HSV · Rainbow · Hot · Cool · Cool-Warm · Blue-White-Red · Red-White-Blue · Grayscale · Spectrum · Terrain · Copper · Bone · Autumn · Winter · Spring · Summer · Ocean · Gist Earth · Gnuplot · Gnuplot2 · Cividis · Twilight · Twilight Shifted · Black-Body Radiation · Seismic · RdBu · RdYlBu · RdYlGn · Spectral · PiYG · PRGn · BrBG · PuOr.
Detection Parameters
ParameterRangeWhat it does
Grayscale Threshold0 – 255Pixels darker than this value are treated as potential flake pixels (dark-on-light substrate). Lower values detect fainter flakes but increase false positives.
Flood-Fill Tolerance1 – 255Maximum luminance or RGB distance from seed pixel during flood fill. Higher values produce larger fill regions. Set to 255 for whole-flake fills.
Min Flake Size10 – 1000 pxMinimum blob area in pixels. Blobs below this threshold are discarded as noise or contamination.
Color Distance5 – 120RGB Euclidean distance from the background colour. Active only in Color Distance mode. More robust on coloured substrates.
Contrast0.5 – 2.0×Visual display contrast multiplier applied before rendering. Does not alter stored measurements or detection.
Brightness0.5 – 2.0×Visual display brightness offset. Does not alter stored measurements or detection.
Erosion Radius1 – 6 pxMorphological erosion kernel size when Morph Cleanup is enabled. Larger values remove more noise but may erode thin or narrow flakes.
Watershed Spliton / offAttempts to separate merged or overlapping blobs by erosion-flood analysis before the final boundary trace.
Morph Cleanupon / offApplies morphological erosion before auto-detection to suppress small noise clusters and isolated pixels.
Layer Thickness Classification (Fresnel Optical Contrast)
Relative contrast = |Lflake − Lsubstrate| / Lsubstrate. Thresholds calibrated for graphene on 300 nm SiO₂/Si (Blake et al., APL 2007; Nair et al., Science 2008).
TagRel. ContrastDefault colour
Monolayer (1L)< 0.030■ Cyan
Bilayer (2L)0.030 – 0.065■ Light Cyan
Few-Layer (3–5L)0.065 – 0.140■ Green
Thick / Bulk> 0.140■ Amber
⚠ Classification accuracy depends on correct scale calibration and background colour estimation. Results for materials other than graphene or substrates other than 300 nm SiO₂/Si should be validated experimentally.
Exports
📄 CSV
Per-flake table: ID, X/Y µm, L, W, Aspect Ratio, Area (µm²), Orientation, Layers, Contrast, Tag, Notes. One row per flake, ready for analysis in Python, MATLAB, or Excel.
📊 Excel (.xlsx)
Two sheets — Summary (aggregate stats + per-layer breakdown) and Flake Data (full inventory with frozen header row and formatted columns).
🖼 JPG Export
Exports a high-resolution composite image. Options shown at export time:
• Include overlays — bounding boxes, labels, crosshairs, origin
• Scale factor — 1× (native), 2× (default), 3×, or 4× for publication-quality output
JPEG quality is set to maximum (1.0 — no compression artefacts). A white background is applied. Output filename includes the scale factor.
🖨 PDF Report
Print-ready analytical report. Summary metrics, per-layer statistics table, and full flake inventory. Open the Report modal and use your browser's Print → Save as PDF to produce the file.
💾 Backup / Restore
Full session JSON — substrate images (base64-encoded), all flake annotations, calibration values, filter settings, ignore areas, and grid layout. Restores the entire session including images on any device.
🎯 Stage Coordinates
Exports flake centroid coordinates as motorised stage visit scripts. Sort order options: raster, centroid-sorted, or spiral scan. For use with automated microscope stage controllers.
📈 Stats Dashboard
4-tab interactive chart suite: size distributions, spatial heat maps, correlation matrix, and cross-image comparison. Individual charts can be exported as PNG images.

Measurement accuracy depends entirely on correct scale calibration (px/µm). Incorrect calibration will produce incorrect dimensional and area values.

Layer classification (Monolayer, Bilayer, Few-Layer) is based on Fresnel optical contrast models calibrated for graphene on 300 nm SiO₂/Si substrates (Blake et al., APL 2007). 🧮 Algorithms Used
Detection
Flood Fill — BFS (Breadth-First Search)
Starts at a seed pixel clicked by the user. A FIFO queue expands to all 4-connected neighbours whose colour distance from the seed is within Tolerance. Runs in O(n) where n = region pixel count. Used for single-click flake segmentation.
Detection
Global Threshold Scan
Sweeps every pixel in a 3 px grid. Pixels darker than Threshold (grayscale) or beyond Color Distance from the sampled background are marked as flake candidates. Connected components are then extracted via BFS. Used for Auto-Detect.
Detection
GMM — Gaussian Mixture Model (Python CLI)
Fits a two-component GMM to the pixel intensity distribution using Expectation-Maximisation (EM). The component with higher mean is treated as the substrate background; pixels assigned to the lower-mean component are flake candidates. More robust than a fixed threshold on non-uniform substrates.
Geometry
Douglas–Peucker Polyline Simplification
Recursively removes vertices from a boundary polygon that deviate less than ε from the line between their neighbours. Reduces flood-fill boundary point count by ~90% while preserving flake shape. Runs in O(n log n) average case.
Geometry
Image Moments & Centroid
Computes raw moments M₀₀, M₁₀, M₀₁ over the pixel set to find the centroid (x̄ = M₁₀/M₀₀, ȳ = M₀₁/M₀₀). Central moments μ₂₀, μ₀₂, μ₁₁ give the inertia tensor. Used for all polygon and flood-fill flakes.
Geometry
PCA Oriented Bounding Box (OBB)
Diagonalises the 2×2 inertia tensor from image moments via eigendecomposition. The principal eigenvector gives the major axis angle θ. Points are rotated by −θ, axis-aligned bounding box computed, then rotated back — yielding the minimum-area OBB. Gives Length, Width, Orientation for every flake.
Geometry
Shoelace Formula (Polygon Area)
Computes signed area of an arbitrary polygon from its vertex list: A = ½|Σ(xᵢyᵢ₊₁ − xᵢ₊₁yᵢ)|. Exact, O(n), used for manually drawn polygon flakes.
Morphology
Erosion + Watershed Split
When two touching flakes produce one large blob, binary erosion (shrinks blobs by Erosion Radius) separates them. Each surviving seed is then re-expanded via BFS flood fill, splitting the original blob into individual flakes. Classic marker-based watershed.
Optics
Fresnel Contrast / Michelson Contrast
Relative contrast C = |L_flake − L_substrate| / L_substrate where L is luminance (Rec. 601 weighted). Calibrated against Blake et al. (2007) APL 91 for graphene on 300 nm SiO₂/Si: 1L ↔ C < 0.030, 2L ↔ 0.030–0.065, 3–5L ↔ 0.065–0.140, Bulk > 0.140. Enables automatic layer counting from a plain optical image.
Statistics
MLE Power Law Fit
Maximum-likelihood estimate for the exponent of a discrete power law: α = 1 + n / Σ ln(xᵢ / x_min). More accurate than least-squares log-log regression. Used in Stats Dashboard to characterise the flake area size distribution.
Statistics
Pair Correlation Function g(r)
Counts all pairwise inter-centroid distances, bins them into annuli of width Δr. Each bin is normalised by the expected count for a completely random (Poisson) point process: g(r) = n(r) / (λ · 2πr·Δr), where λ is flake density. g(r) > 1 → clustering, g(r) < 1 → spatial repulsion.
Statistics
Nearest-Neighbour Distance (NND) Histogram
For each flake centroid, finds the closest other centroid using an O(n²) exhaustive search (n is typically small). Histogram of these distances characterises flake spatial regularity. Compared to the theoretical Rayleigh distribution for a random process.
Statistics
Pearson Correlation Matrix
Computes all pairwise Pearson r coefficients among 5 flake metrics (Area, Length, Width, Aspect Ratio, Contrast): r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]. Visualised as a 5×5 colour heatmap. Reveals which physical quantities co-vary.
Alignment
Harris + Patch Descriptor + RANSAC (Image Stitch)
Images are downsampled to ≤600px wide to bound memory use. Sobel gradients → structure tensor (box-smoothed) → Harris response R = det(M)−k·tr(M)². Top-250 corners kept after non-maximum suppression. Each corner gets an 11×11 zero-mean-normalised patch descriptor. Mutual nearest-neighbour matching with Lowe's ratio test (threshold 0.75) produces candidate correspondences. RANSAC (each match as a 1-point translation hypothesis) finds the inlier-maximising (dx, dy). Offsets are scaled back to full resolution. Graph-based greedy placement handles more than 2 images in any arrangement.
Coord
Affine Screen ↔ World Transform
All canvas interactions use a two-level affine transform: Screen → Image pixel via (x − pan) / zoom, then Image pixel → Physical µm via (pixel − origin) / scaleRatio with optional Y-axis inversion for Cartesian convention. Inverse path used for rendering.
Colour
Scientific Colormap Interpolation (39 maps)
Each colormap is stored as an array of 5–12 [R, G, B] control points sampled at equal spacing across [0, 1]. Given a normalised value t, the surrounding pair of stops is found via floor(t·(n−1)) and a linear blend applied channel-wise. For each flake at index i, three t-values are derived (t, t+0.33, t+0.67 mod 1) to assign distinct hues to the outline, the L×W dimension string, and the crosshair arm labels. Maps include perceptually uniform (Viridis, Plasma, Magma, Inferno, Cividis), diverging (RdBu, Seismic, BrBG, etc.), cyclic (HSV, Twilight), and legacy (Jet, Rainbow, Hot, Cool) colormaps.
Export
High-Resolution JPG Composite Export
An off-screen canvas is created at exportWidth × exportHeight × SCALE pixels (SCALE ∈ {1, 2, 3, 4}, default 2). A white fill prevents the JPEG black-background artefact. All substrate images are drawn via ctx.scale(SCALE, SCALE) so the native image pixels upscale without interpolation loss. Flake overlays (outlines, labels, crosshairs) are re-rendered at the same scale. The canvas is serialised with toDataURL('image/jpeg', 1.0) — quality 1.0 is the JPEG maximum, producing near-lossless output. A 2× export of a 3 MP substrate yields a ~12 MP file.
